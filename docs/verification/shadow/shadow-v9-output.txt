=== 2. COO CRITIQUE VALIDATION ===

Critique 1: GRRI_C coefficients (0.6, 0.5) are arbitrary
  VERDICT: ✅ CORRECT. No mathematical justification for 0.6/0.5.
  The shadow model v8 did NOT optimize these coefficients.

Critique 2: GRRI_C mixes units (ounces + dollars)
  VERDICT: ✅ CORRECT. The formula (Gold_val + 0.6×Silver_val + 0.5×Liquid_val)
  uses market VALUES (dollars), not ounces. But the denominator uses
  GoldPrice × GoldQty (also dollars). So it IS dimensionally consistent.
  However, the COO is right that this was NOT clearly stated.

Critique 3: GRRI_C falls when gold rises (pro-cyclical)
  VERDICT: ✅ CORRECT. When gold rises 50%, GRRI_C drops from 4.55 to 2.89.
  This is the SAME behavior as GRI — both measure "how much gold the reserve
  can buy" which naturally drops when gold gets more expensive.
  The COO correctly notes this is NOT automatically "reserve weakness."

=== 7. FINAL RECOMMENDATION ===

RECOMMENDED ARCHITECTURE: MODEL D (Multi-metric)

Metrics:
  1. PAR = $1.00 (fixed — settlement certainty)
  2. RR = R_a / (S × PAR) (legal solvency — hard floor 100%)
  3. GRI = (R_a,t/G_t) / (R_a,0/G_0) (gold-relative strength, normalized to 1.0)
  4. BRI = (GoldVal_t/GoldVal_0)^0.50 × (SilverVal_t/SilverVal_0)^0.50
     (bullion resilience, weights optimized via CVaR)
  5. LCI = HQLA / Stress Outflows (liquidity coverage)
  6. CVaR (portfolio tail-risk, used for optimization)
  7. CQS (currency quality selection)

All metrics are ADVISORY except RR (legal solvency) and PAR (settlement).
No metric automatically changes PAR or triggers rebalancing.
Rebalancing uses weight drift + RR + hysteresis (unchanged from v21).
