=== 3. ROOT CAUSE ANALYSIS ===

The COO formula: Reserve_Strength = Total_Reserve_Value / Gold_Price

When gold price rises:
  - Total Reserve Value rises (because reserve holds 15% gold)
  - Gold Price (denominator) rises FASTER (because it is 100% gold)
  - Net effect: Reserve Strength DROPS (reserve has only 15% gold, not 100%)

This is mathematically equivalent to: "How many ounces of gold can the reserve buy?"
  - If gold doubles and reserve only rises 15%, the reserve buys FEWER ounces
  - This is TRUE in purchasing-power terms, but...
  - ...making it the PRIMARY rebalancing trigger creates pro-cyclical behavior
