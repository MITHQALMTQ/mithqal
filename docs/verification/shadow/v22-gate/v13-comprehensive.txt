=== 1. MATHEMATICAL EQUATIONS ===

ALL MODELS share these core formulas:
  PAR = $1.00 (fixed)
  RR = R_a / (S × PAR)
  R_a = Σ Q_a × P_a × (1 − H_a) × C_a
  LCR = HQLA / 30-day net outflows
  HQLA = cash + sovereign×0.98 + stablecoin×0.98

v22+ ADDS:
  GEI = (R_a,t / G_t) / (R_a,0 / G_0)  [normalized gold-equivalent]
  BRI = (GoldVal_t/GoldVal_0)^0.85 × (SilverVal_t/SilverVal_0)^0.15
  LCI = HQLA / (S × 0.10)
  Optimizer: W* = argmax [λ₁·RR + λ₂·LCR + λ₃·GEI − λ₄·CVaR − λ₅·FXRisk − λ₆·GeoRisk − λ₇·Concentration]

Model K ADDS (mathematically = v22):
  MRR_j = (R_a/FX_j) / (S×PAR/FX_j) = R_a/(S×PAR) = RR  [PROVEN INVARIANT]
