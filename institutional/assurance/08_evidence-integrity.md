## 3. Modification Handling

When an evidence record is modified:
1. The original record is NOT modified (append-only per K-04).
2. A new record is created with a new `event_id` and new `integrity_hash` (K-01, K-02).
3. The new record references the original via `prior_version_ref`.
4. The modification log entry is created (K-10) with actor, timestamp, before-hash, after-hash.
5. Separation of duties (K-05) applies: the modifier ≠ the approver.
6. If the modification is contested, the prior version remains available for dispute (per `24_management-response.md`).
